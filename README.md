
O projeto LigaNOS Management System é uma aplicação web desenvolvida com ASP.NET Core MVC para a gestão de clubes, jogadores, jogos e estatísticas da LigaNOS.

 ![image](https://github.com/user-attachments/assets/6be047e4-5055-4106-af61-606e3c481cc4)


Funcionalidades

- Aplicação Web (ASP.NET Core MVC)

- Gestão de Clubes: CRUD completo de clubes com upload de imagens.

- Gestão de Jogadores: CRUD completo de jogadores, com associação aos respetivos clubes.

Gestão de Jogos:
![image](https://github.com/user-attachments/assets/fea7afa2-7a2d-4317-b763-e68cead5dc06)


- Agendamento de jogos com gerador automático de partidas.

- Inserção e edição de resultados (golos e estádios).

Gestão de Estatísticas:

![image](https://github.com/user-attachments/assets/9e108302-68da-472a-b6ec-a8dfb42c0f33)


- Página de estatísticas com classificação geral dos clubes.
  
 

- Estatísticas detalhadas, como vitórias, derrotas, empates, golos marcados e sofridos.
